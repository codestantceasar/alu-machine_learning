# Optimization

This project covers optimization techniques used in machine learning and deep learning.

## Learning Objectives

- Normalize and standardize data
- Shuffle datasets for training
- Implement mini-batch gradient descent
- Understand moving averages
- Implement Momentum optimization
- Implement RMSProp optimization
- Implement Adam optimization
- Apply learning rate decay
- Use TensorFlow optimization operations

## Files

| File | Description |
|------|-------------|
| `0-norm_constants.py` | Calculates normalization constants |
| `1-normalize.py` | Normalizes a dataset |
| `2-shuffle_data.py` | Shuffles data points consistently |
| `3-mini_batch.py` | Trains a neural network using mini-batch gradient descent |
| `4-moving_average.py` | Computes moving averages with bias correction |
| `5-momentum.py` | Momentum optimization in NumPy |
| `6-momentum.py` | Momentum optimization in TensorFlow |
| `7-RMSProp.py` | RMSProp optimization in NumPy |
| `8-RMSProp.py` | RMSProp optimization in TensorFlow |
| `9-Adam.py` | Adam optimization in NumPy |
| `10-Adam.py` | Adam optimization in TensorFlow |
| `11-learning_rate_decay.py` | Learning rate decay in NumPy |
| `12-learning_rate_decay.py` | Learning rate decay in TensorFlow |

## Requirements

- Ubuntu 16.04 LTS
- Python 3.5
- NumPy 1.15
- TensorFlow 1.12
- pycodestyle 2.4

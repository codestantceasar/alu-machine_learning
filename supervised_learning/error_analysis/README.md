# Error Analysis

This project focuses on evaluating the performance of machine learning classification models using confusion matrices and common evaluation metrics.

## Learning Objectives

At the end of this project, I should be able to explain:

* What a confusion matrix is
* Type I and Type II errors
* Sensitivity (Recall)
* Specificity
* Precision
* F1 Score
* Bias and Variance
* Bayes Error
* How to calculate bias and variance
* How to create a confusion matrix

## Tasks

### 0. Create Confusion

Create a confusion matrix from one-hot encoded labels and predictions.

### 1. Sensitivity

Calculate the sensitivity (recall) for each class.

### 2. Precision

Calculate the precision for each class.

### 3. Specificity

Calculate the specificity for each class.

### 4. F1 Score

Calculate the F1 score for each class.

### 5. Dealing with Error

Identify solutions for different bias and variance scenarios.

### 6. Compare and Contrast

Analyze model performance using confusion matrices and human-level performance.
